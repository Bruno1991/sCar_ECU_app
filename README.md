# s_Car_ECU_app 🚗⚡

Aplicativo de Diagnóstico Automotivo, Telemetria e Leitura de ECU / OBD-II com alta fidelidade e conectividade em tempo real.

## Visão Geral
* **Domínio:** Telemetria Veicular, CAN Bus, OBD-II e Gestão de ECU
* **Arquitetura:** Clean Architecture com desacoplamento de protocolos de transporte (Bluetooth ELM327, USB/Serial, WiFi)
* **Ecossistema:** Integrado ao `sEcoSys` (Elias Bruno Silva - `Bruno1991`)
